Agent tool-boundary enforcement · multi-agent collusion carriers

AgentGate: Deterministic Guardrails Against Multi-Agent Collusion Carriers

A Policy Enforcement Point (pep.py) bound to 127.0.0.1 sits in the tool loop of a registered agent or MCP client and decides every tools/call before it runs. It addresses three ways agents can coordinate past a content filter—post-taint side channels, delegation laundering, and split or encoded smuggling—with arithmetic, hashing, and HMAC on the call path. No model is consulted to reach a decision.

Abstract

Agents that share tools can leak through which argument they pick and when they call, can launder a restricted capability by handing work to a clean peer, and can move a protected value in small or re-encoded pieces. AgentGate bounds the first with a post-taint side-channel guard, defeats the second with monotonic chained-HMAC capability attenuation across delegation, and catches the third with salted n-gram fingerprints over decoded forms plus zero-width canary watermarks. In the recorded run the repository’s carrier tests passed 57 of 57, 750 benign decisions produced no denials, and per-decision CPU time had a p50 of 0.126 ms and a p99 of 0.999 ms against a 2 ms reference; the slowest single decision took 3.84 ms. These are same-author lab checks, stated with their limits in §5.

§4

Reproduce in about 30 seconds

The evaluation itself runs in about 5 s after install. It binds no port, makes no network call, and writes the JSON, Markdown, PDF report, and slide deck to the folder you name. Latency will differ by machine.

git clone https://github.com/freeling10-prog/rogue-ai-detection
cd rogue-ai-detection/agent-gateway
python -m pip install -e '.[test]'
export AGENT_GATEWAY_HMAC_KEY="$(python -c 'import secrets; print(secrets.token_hex(32))')"
python -m agent_gateway evaluate-collusion --report ./audit_out
Request a Tier 1 diagnostic on your MCP servers

To re-record the §3 traces: python ../examples/record_site_traces.py from the same directory with the same key exported.

Claude Code PreToolUse hook, one command

python -m agent_gateway.claude_code_hook --install

Adds one PreToolUse command hook to ~/.claude/settings.json (running it again adds nothing). Before each tool call it denies credential paths (.env but not .env.example, ~/.ssh, ~/.aws, .npmrc, .pypirc), recursive home or root deletion, force pushes to main, download-to-shell pipes, and link-local metadata or file:// targets, and appends a SHA-256 hash-chained entry to ~/.claude/agentgate_audit.jsonl. --self-test runs four validation checks and prints CPU time per decision. Lexical configuration checks, not a sandbox.

§5

Scope, threat model & non-goals

What the numbers above do not say.

Same-author lab checks
The carrier scenarios and the benign workflows were written by the person who wrote the guards. 57/57 shows the guards behave as their tests specify; it is not recall against an unknown adversary. 0/750 is a smoke check, not a false-positive rate for a deployment.
2 of 13 stays separate
The only real-model figure is a loopback archive: qwen2.5:3b against the localhost honeypot, 2 of 13 non-control runs, one machine. It is a different measurement and is never pooled with the lab checks. Not a benchmark.
Loopback only
Default bind is 127.0.0.1. A non-loopback bind needs an explicit flag and an isolated lab network. No public honeypot is deployed; honeypot output is leads for a person.
15-minute lab key freeze
Freeze applies only to keys in the lab registry, for 900 seconds. An unregistered key is never frozen.
Approximate ATLAS
MITRE ATLAS ids are the project’s approximate mappings. Not a certification, and not a statement that anything passes ATLAS, OWASP, NIST, SOC 2, or ISO.
Routed calls only
Calls that bypass the gateway are not seen. An untrusted source that is never labeled never taints a session. Answer-only injections that trigger no gated call are out of scope.
Not a sandbox
No OS sandboxing or network isolation. Anyone holding AGENT_GATEWAY_HMAC_KEY can mint capabilities; key rotation is not implemented. Tool backends in the lab are simulated echoes.
v12.1 guard limits
Inline interpreter writes (python -c, node -e, ruby -e, perl -e, php -r, heredocs, decoded pipes) and MCP tools over-privileged from their first listing are now enforced by interpreter_exec_guard.py and mcp_capability_manifest_guard.py. Both are static: code fetched or decrypted at run time, a path computed from runtime input with no protected literal in sight, or a script file run by name (python x.py) is not analysed, and a tool with a clean schema can still misbehave on its server. An encrypted or paraphrased payload is still not caught. cross_agent_collusion_guard.py sees only routed notes, files, bus messages, and delegations; its labels never decay, so a long-lived shared artifact stays tainted.
v12 guard limits
Lexical and deterministic. mcp_rugpull_guard.py pins what it first sees; the v12.1 capability profile now checks that first listing, but a description can still mislead in plain words. workspace_config_guard.py reads paths and command words; inline interpreter writes are now covered by interpreter_exec_guard.py. control_flow_integrity_guard.py classifies tools by name and argument keys; in the engine a manifest only narrows. stego_exfil_guard.py misses a paraphrased or encrypted secret and one leaked a character per identifier.
v11 guard limits
schema_integrity_guard.py compares digests and normalized names, not what a description means. gui_action_guard.py checks coordinates and key names against configured rectangles and a deny-list; it does not look at the screen. temporal_accumulator_guard.py matches registered tokens and watermark characters within a bounded sliding window per (session, destination); it does not catch a paraphrased value or pieces spread across destinations. memory_provenance_guard.py tracks only resources written through routed tool calls, and its ledger lives in memory unless exported with export_provenance_ledger().
Not a pen test
Not a penetration test, not a red team of anyone’s users, and not legal advice.
