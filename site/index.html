Taint-and-Freeze Simulator

Four canned walkthroughs of the real gateway modules. Everything runs in vanilla JavaScript on this page: no network calls, no sign-in, no backend. Colors follow the engine’s own states — verified / pinned, tainted / held, denied / frozen.

mcp_proxy.py + tool_output_scanner.py

≈ AML.T0051 (approximate)

The wire proxy pins sha256(name, description, inputSchema) on the first tools/list. A later listing that mutates a pinned tool is a rug pull; hidden Unicode tag characters (U+E0000) and cross-tool name shadowing in tool output are flagged; the session agw1. capability is attenuated to allow_egress=false and later calls wait for a person.

deobfuscate.py

≈ AML.T0086 (approximate)

After a SENSITIVE_READ, the gateway keeps salted rolling n-gram digests of the secret and its Base64 / hex / URL / whitespace-stripped forms. Outbound tool arguments are concatenated across steps, so a secret leaked 4–6 characters per call — raw or encoded — is still caught. On a match the call is denied and the registered lab key is frozen for 15 minutes.

toxic_combinations.py

≈ AML.T0086 (approximate) · static reachability

python -m agent_gateway audit --tool-inventory tools.json enumerates every 2-hop and 3-hop path where an external_read can reach a send / write / credential_use sink. Toggle a hard agw1. boundary on a sink to watch its paths flip from toxic to protected. This is static analysis of a declared tool list — not a penetration test.

audit_chain.py + OOB approval

tamper-evident receipts

A held call is formatted in-process as a scrubbed Slack Block Kit payload: capability state, taint source, approximate ATLAS id, and one-time callback MACs shown only as SHA-256 fingerprints. Every decision-log line is SHA-256 hash-chained, and python -m agent_gateway verify <audit_dir> recomputes the chain and the audit_manifest.json digests.
