Runtime boundary evidence, checked by bounded enumeration, showing which AI agent and MCP tool calls were allowed or blocked.

  • SHA-256 pins on each MCP tool’s name, description, and input schema. A listing that changes a pin is denied. A schema-integrity or rug-pull update is accepted only with an HMAC made from the gateway key.
  • Tamper-evident SHA-256 hash-chained decision log. Editing, dropping, or reordering a line breaks the chain. An HMAC-SHA256 audit manifest covers the report files.
  • Argument guard for paths, shell text, and mutating queries. Egress URI guard for internal and cloud-metadata targets, with no DNS lookup. Workspace mutation checks on creates, deletes, and renames.
  • Static 2-hop and 3-hop toxic tool combinations: an untrusted read, then a sensitive or internal read, then a sink. A runtime hold on the lethal trifecta when a tainted or egress-closed session has read sensitive data and then places parameters on an external boundary.
  • HMAC capability tokens (agw1 and agw2). Caveats only narrow what the holder may call.
  • P3 leakage budget, an integer count of quarter-bits, one ledger for a coalition of sessions.
  • HTML audit-report export and OASIS SARIF 2.1.0 export.

P3 leakage budget, calibrated in log-only mode

Turning blocks on before the budget has seen real traffic breaks production workflows. P3 is deployed in log-only mode first. Every charge and every would-be hold is recorded on benign traces. Enforcement is turned on after that calibration.

One coalition ledger

  • Coalitions of linked sessions share one integer quarter-bit budget (default 32 bits).
  • Every outbound event pays for continuation bit + Elias-gamma timing gap + member choice + tool selection + content (typed field codes or raw-DEFLATE length).
  • Withheld results never refund budget charges.
  • Over-budget events return JSON-RPC -32082 and are held for human approval, never auto-released.
  • One shared outbound check across the engine.
  • Core MCP server names are loaded once per engine.

Stated limitRegular-rhythm timing beacons are flagged; irregular timing channels are not yet bounded.

Validator layer

A call is admitted only if every attached predicate admits it. Each one is inert until a trusted adapter attaches its state, and state is committed only after all of them pass. Denials use JSON-RPC -32066 through -32080. An over-budget P3 event returns -32082 and is held for a person. Checked by bounded enumeration.
